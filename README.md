# 📖 About

CareWave is a Final Year B.E. Computer Engineering team project developed to provide a reliable emergency response platform for personal safety.

The system enables users to trigger SOS alerts, monitor GeoFence boundaries, share live locations with guardians, receive disaster notifications, and access AI-powered emergency assistance through a secure backend built using Spring Boot.

This repository serves as a **project showcase**, containing project documentation, architecture, screenshots, and my contributions as **Team Leader and Backend Developer**.

The backend source code is maintained in the shared team repository.

---

# 🎯 Problem Statement

In emergency situations, users often struggle to notify family members quickly, share their live location, or access nearby emergency services.

CareWave addresses these challenges by providing a centralized emergency response platform that combines SOS alerts, live tracking, GeoFence monitoring, guardian connectivity, and intelligent emergency assistance.
